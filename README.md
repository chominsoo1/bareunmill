# 바른밀제빵소 온라인 도구 (영구 주소)

부산 해운대 중동역 유기농 우리밀 베이커리 **바른밀제빵소**의 손님용 웹 도구를 GitHub Pages로 서비스합니다.

| 경로 | 내용 |
| --- | --- |
| `/` | 공식 링크 안내 (litt.ly/bareunmill 연결) |
| `/order/` | 당일 빵 라인업 & 주문예약 (초경량 주문서) |
| `/calc/` | 베이커스 % · DDT 물온도 계산기 |
| `/convert/` | 제빵 재료 만능 환산기 (우유·탈지분유 / 이스트 3종 / 버터·오일 / 생크림 / 설탕·꿀 / 달걀 / 밀가루 / 버터밀크) |
| `/bake/` | 반죽 분할·르방 피딩 계산기 (반죽 분할·발효 손실률 / 르방 피딩) |
| `/oven/` | 오븐 온도·시간 변환기 (데크·컨벡션·가정용·에어프라이어 환산 / 품목별 굽기 기준) |

공식 프로필: https://litt.ly/bareunmill
