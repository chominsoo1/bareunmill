# 바른밀제빵소 온라인 도구 (영구 주소)

부산 해운대 중동역 유기농 우리밀 베이커리 **바른밀제빵소**의 손님용·제빵사용 웹 도구를 GitHub Pages로 서비스합니다.

| 경로 | 내용 |
| --- | --- |
| `/` | 공식 링크 안내 (litt.ly/bareunmill 연결) |
| `/order/` | 당일 빵 라인업 & 주문예약 (초경량 주문서) |
| `/calc/` | 베이커스 % · DDT 물온도 계산기 |
| `/cost/` | 제빵 원가 계산기 (초슬림) |
| `/sourdough/` | 유기농 우리밀 사워도우 전용 계산기 (사내용) |
| `/admin/` | 사장님 통계 대시보드 (비공개 목적) |

공식 프로필: https://litt.ly/bareunmill
